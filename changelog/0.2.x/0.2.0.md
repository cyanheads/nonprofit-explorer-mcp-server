# 0.2.0 — 2026-10-21

## Added

- **990-PF financials:** expose `grants_paid`, `distributable_amount`, `fair_market_value_assets`, and `net_investment_income`; the distributable amount is a payout requirement, not actual payments or a compliance measure ([#19](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/19)).
- **`filing_count_pdf_only`:** count PDFs separately from extracted filings and direct PDF-only profiles to filing links without inferring a financial snapshot ([#21](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/21)).

## Changed

- **Search tool:** Rename `nonprofit_search` to `nonprofit_search_organizations`; update callers to use the new name ([#16](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/16)).
- **Development guidance:** synchronize framework references and release procedures; use Bun 1.4.2 → 1.4.3 for development and container images.

## Fixed

- **Form-specific financials:** select 990, 990-EZ, and 990-PF source fields per filing; preserve reported zero and missing values. PF investment income requires both savings-interest and dividend components ([#18](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/18)).
- **Service failures:** omit request URLs from service error data and debug metadata; keep network exceptions as internal causes behind a stable public message ([#14](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/14)).
- **Cancellation and timeouts:** preserve caller cancellation, distinguish attempt expiry from upstream failures, and enforce the derived 64,375 ms total retry deadline with post-read abort checks ([#20](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/20)).
