# 0.3.0 — 2026-11-03

## Added

- **`latest_return`** identifies the newest return across extracted and PDF-only histories; PDF-only output retains full tax periods ([#23](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/23)).
- **BMF filing requirements, affiliation, and group exemption number** contextualize missing history without inferring its cause ([#25](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/25)).
- **`from_year` / `to_year`** select inclusive fiscal-year windows across both filing collections while retaining unfiltered totals ([#26](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/26)).
- **Fundraising and Part IX figures** expose eight nullable financial fields, keeping 990 event amounts distinct from 990-EZ combined gaming/fundraising amounts ([#27](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/27)).
- **`nonprofit-explorer-guide`** supplies diligence and comparison gates through plugins, npm, Docker, desktop bundles, and MCP skill resources.

## Changed

- **Search filters** accept state/territory names and case-insensitive NTEE major letters, normalized to upstream codes; secondary-name descriptions reflect repeated legal names ([#28](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/28)).
- **Filing rendering** groups invariant notes by form and preserves every field's null meaning; upstream strings and source links retain their values through CommonMark rendering.
- **Packaging and development tooling** support Agent Plugins root manifests and published skills; desktop bundles exclude authoring/build files while retaining SDK skill runtime modules.

## Fixed

- **`executive_compensation.field_name`** is nullable for 990-EZ, whose extract has no compensation source; its amount stays null and guidance points to Part IV ([#24](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/24)).
- **`latest_filing`** is labeled as the latest extracted snapshot, and both filing histories sort by full tax period without discarding ties or implying amendment precedence.
