# 0.4.0 — 2026-11-20

## Added

- **`nonprofit_get_organization`** returns the latest e-file object ID and ProPublica viewer URL when available. Check the viewer's reporting period before using it for a specific year. ([#30](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/30))
- **`nonprofit_get_filings`** reports the earliest and latest known fiscal years for the complete extracted and PDF-only histories, including when the selected interval is empty. ([#34](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/34))
- **`ntee_category`** accepts full codes such as `K31` and `A6AI` to select their major group. Use each result's `ntee_code` for exact-code comparisons. ([#33](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/33))

## Changed

- Fiscal-year bounds on nonprofit_get_filings now require four-digit integers (1000–9999). Omit a bound for an open interval. (#34)
- Earlier versions accepted any integer as a fiscal-year bound. With both bounds omitted, results can include undated filings. [#34](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/34)
- **`nonprofit_search_organizations`** documents required terms across name and city, such as `+opera +seattle`, and suggests them after an unquoted multiword query returns zero matches. ([#32](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/32))
- **Filing source guidance** points to the reporting period in the latest e-file viewer and the individual PDF for a historical return. The nonprofit-explorer guide is now 1.1. ([#30](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/30))
- **Runtime and release tooling** require Bun 1.4.4 or later for Bun installations and update framework documentation, package validation, and Desktop bundle cleanup.

## Fixed

- **IRS Business Master File amounts** show their own reporting month. `income_amount` means computed gross receipts, and both the BMF period and ruling date use day `01` as a month placeholder. ([#31](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/31))
- **`nonprofit_get_filings`** adds `strein` and renders the full formatted EIN, including leading zeros. ([#35](https://github.com/cyanheads/nonprofit-explorer-mcp-server/issues/35))
- **Search results** format the numeric EIN with leading zeros when ProPublica omits `strein`.
