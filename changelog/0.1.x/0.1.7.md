# 0.1.7 — 2026-08-12

## Fixed

- **`nonprofit_get_filings`'s `executive_compensation`** is no longer nullable — the block is present on every filing regardless of form type. `form_type` and `field_name` are narrowed from bare strings to enums matching the values the code actually emits. (#12)
- **Tool description and field-description strings** across all three tools no longer use `+`-concatenation, which risked silently fusing words together if a boundary space were dropped; rendered schema output is unchanged. (#13)
