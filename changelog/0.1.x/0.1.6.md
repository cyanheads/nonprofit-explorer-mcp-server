# 0.1.6 — 2026-08-12

## Added

- **IRS Business Master File classification** on `nonprofit_get_organization` — `deductible`, `exempt_status`, `foundation_type`, and `bmf_tax_period`, each decoded from its IRS code as `"<code> — <meaning>"` with the raw code retained. (#3)

## Changed

- `sort_name`/`sub_name` relabeled across all three tools as the IRS Business Master File secondary name line — an internal sort key, not an alternate organization name.
- 501(c)(3) description corrected: it covers both public charities and private foundations, not "public charity" alone; `foundation_type` now distinguishes them.
- `docs/idea.md` marked as a superseded pre-build document; `docs/design.md` is the accurate reference.

## Fixed

- **`nonprofit_get_filings` program-expense ratio** is now always `null` instead of an approximation computed from inputs that cannot produce it — ProPublica returns no Form 990 Part IX column (B) program-service total. (#4)
- **Null-valued fields** now render in `format()` across all three tools instead of being silently omitted, each labeled with why it's absent. A populated `revenue_amount` no longer disappears when `asset_amount` and `income_amount` are null. (#8)
- **`nonprofit_get_filings`** — an EIN resolving to a real organization with no 990 on record now returns a successful empty `filings` array with an enrichment notice instead of throwing `no_filings`; that error reason is dropped from the tool's contract. (#9)
- **`nonprofit_search`** — the 10,000-result cap caveat now reaches `structuredContent` via `ctx.enrich.notice`, not just the formatted text; also corrects "1 pages" pluralization and "0–0" range phrasing on a single-page past-the-end result. (#10)
- Tool descriptions and README no longer claim XML filing links — only the PDF link (`pdf_url`) is returned. (#7)
