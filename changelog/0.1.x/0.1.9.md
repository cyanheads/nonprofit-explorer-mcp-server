# 0.1.9 — 2026-09-20

## Changed

- **Argument rejections return `InvalidParams` (-32602)** instead of `ValidationError` (-32007), carrying `data.reason: "invalid_arguments"` and a schema-derived recovery hint rendered as a `Recovery:` line in `content[]`.
- **Tool error text closes with `(reason … · not retryable)`** whenever the thrown error's data carries a `reason` or a boolean `retryable`.
- **Tool arguments pass a pre-validation step before schema parsing** — a client-added root key is dropped, a case-style key alias is rewritten, and a JSON-stringified array argument is repaired once before a call fails.
- **A request cancelled mid-flight classifies `RequestCancelled` (-32011)** instead of a generic internal error.
- **`createApp()` declares `sessionMode: 'stateless'` in code**, and each service-thrown `not_found` / `upstream_error` / `pagination_ceiling` reason carries `thrownBy: 'service'`.
- Skill tree moved `skills/` → `framework-skills/` (dev tooling; not part of the published package).
