# 0.1.10 — 2026-10-08

## Changed

- **Tool arguments are repaired instead of rejected in three cases**: an integer sent for `query` becomes its digits (`4711` searches for "4711"), a numeric string for `page` becomes the integer (`"1"` → page 1), and `null` at an optional filter (`state`, `ntee_category`, `subsection_code`) is treated as absent.
- **Tool error results carry `data.requestId`**, and the error text closes with `request <id>`.
- **Argument-rejection hints name the field path**, e.g. `Send page as a number, not a boolean.`
- **Service and tool throw sites no longer forward `ctx.recoveryFor(…)`**; the framework fills the declared `recovery` hint for the thrown `reason`. Callers see the same hint text as before.
- **`Dockerfile` installs production dependencies in a `deps` stage on `$BUILDPLATFORM`**, using the new `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts`. Multi-arch builds no longer run Bun under emulation, and the image drops the unused musl native bindings.
- **Bun `1.4.0` → `1.4.2`** in `packageManager`, the Docker base images (`oven/bun:1.4.2`), and the README badge.
- **`package.json` `files` excludes `dist/*.mcpb`**; `.mcpbignore` excludes `.cache/`, `coverage/`, `tests/`, `docs/idea.md`, and `logs/`; `.gitignore` and `.dockerignore` ignore every `.env*` file except the templates.
- **`.github/workflows/codeql.yml` runs `actions` and `javascript-typescript` as a matrix**, each uploading under `/language:<language>`.
- **`.env.example` and the README document** the framework's logging, request-state, resumability, and OTLP variables, including `LOG_TOOL_FAILURE_PAYLOADS`.
- Framework skills, devcheck and lint scripts, `CLAUDE.md`, and `AGENTS.md` synced to `@cyanheads/mcp-ts-core` 0.13.14; `package.json` gains `audit:fix` and `start` scripts.

## Fixed

- **MCP Registry `server.json`**: both npm package entries now use `"runtimeHint": "npx"` with no `packageArguments`, and the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http`. The package bin ignored the former `run start:*` arguments, so the HTTP entry never selected the HTTP transport.
